# AI Tools Setup Project

## Overview
This project documents the process of setting up Cursor IDE along with Claude Code and Codex extensions, and connecting the local environment to GitHub.

## Tools Installed
- Cursor IDE
- Claude Code extension
- Codex extension
- GitHub

## Steps Completed
1. Installed Cursor IDE
2. Explored the interface and located extension marketplace
3. Installed Claude Code and Codex extensions
4. Logged into both tools
5. Created a GitHub repository
6. Connected local project to GitHub using terminal
7. Created and pushed this README file

## Challenges Faced
Initially, I found Cursor’s interface confusing, especially locating extensions and understanding how to switch from agent view to editor mode. 

I also faced issues during GitHub authentication, where the terminal appeared unresponsive and required multiple attempts to complete the login process.

## Learnings
This task helped me understand how AI tools integrate into development workflows, how Git and GitHub work together, and the importance of persistence when debugging issues during setup.
